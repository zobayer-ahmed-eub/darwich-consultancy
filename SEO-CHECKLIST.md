# Darwich Consultancy SEO checklist

Included in code:
- Unique titles and descriptions
- Dynamic service SEO fields
- Canonical URLs
- Open Graph / WhatsApp previews
- Twitter/X card tags
- 1200×630 social preview image
- robots.txt
- dynamic sitemap.xml
- ProfessionalService + WebSite schema
- Service schema for published consultancy services
- AboutPage and ContactPage schema
- noindex for admin/cart/checkout
- Search Console verification support
- GA4 support

After launch:
1. Add the real phone, email, address, trade licence/registration and social links in Admin.
2. Publish real management profiles, projects and images.
3. Add real SEO titles/descriptions to important services.
4. Verify `darwichconsultancy.com` in Google Search Console.
5. Submit `https://darwichconsultancy.com/sitemap.xml`.
6. Request indexing for Home, Services, Projects, About and Contact.
