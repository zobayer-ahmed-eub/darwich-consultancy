# Google Search Console

Recommended property: `darwichconsultancy.com` using the **Domain** property type.

1. Open Google Search Console.
2. Add `darwichconsultancy.com`.
3. Copy the DNS TXT record Google provides into Hostinger DNS.
4. Verify ownership.
5. Submit sitemap: `https://darwichconsultancy.com/sitemap.xml`.
6. Optionally add the verification token to `GOOGLE_SITE_VERIFICATION` in Hostinger environment variables.
