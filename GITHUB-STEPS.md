# GitHub deployment steps

Suggested repository: `darwich-consultancy`

```bash
git init
git add .
git commit -m "Initial Darwich Consultancy website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/darwich-consultancy.git
git push -u origin main
```

For future updates:

```bash
git add .
git commit -m "Update Darwich website"
git push
```
