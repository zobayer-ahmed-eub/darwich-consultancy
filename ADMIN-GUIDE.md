# Darwich Admin Guide

Open `/admin/login` and sign in with the credentials configured in Hostinger environment variables.

## Settings
Update business name, phone, email, service area, office address, trade licence / registration, logo, social links, currency and booking/payment settings.

## Services & fees
Create, edit or remove consultancy services. Each service supports:
- URL slug
- service title and category/kicker
- short + full description
- starting fee and price unit
- service image
- published / featured controls
- consultation and proposal buttons
- sort order
- SEO title + SEO description

## Consultation packages
Optional fixed-scope offerings such as site visits, drawing reviews or preliminary consultations. Packages support price, sale price, deposit, image, description and booking controls.

## Consultation bookings
Review submitted package bookings, change request status and payment status, and manage preferred date/time.

## Management
Publish directors, architects, engineers, quantity surveyors, project managers or other company profiles.

## Projects / Gallery / Testimonials
All are editable from the dashboard and appear automatically on the public website when published.

## Enquiries
Contact-form submissions are stored in MySQL and can be marked new, contacted, quoted or closed.
